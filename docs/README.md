# Documentation

Project documentation is organized by purpose:

- `architecture/`: system context, component design and data flows.
- `decisions/`: Architecture Decision Records (ADRs).
- `standards/`: engineering and data standards.
- `business/`: business requirements, KPI definitions and use cases.
- `task-reports/`: báo cáo thay đổi của từng task, phân cấp theo ngày thực hiện.
