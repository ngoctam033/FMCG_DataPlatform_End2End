# Simple Generators

Khu vực này chứa các kịch bản/logic sinh dữ liệu (data generation) đơn giản, đóng vai trò như các hệ thống nguồn (Source System) phục vụ cho MVP.

Các bộ sinh dữ liệu này được phân chia thành các thư mục nhỏ dựa trên miền dữ liệu (data domain) của FMCG, ví dụ như POS, Inventory, Product Master, v.v.

Trong tương lai, nếu một miền dữ liệu được cấp phát một hệ thống nguồn hoàn chỉnh (ví dụ: cài đặt Odoo ERP thực tế), nó sẽ được chuyển ra thư mục ngang hàng với `simple-generators`.
